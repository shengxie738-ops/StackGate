# SG-037 JUnit collection

JUnit runs the reviewed command once and captures only `junit.xml` in the authorized current attempt output directory. A preexisting report is rejected without deleting it. Directory identity, regular-file identity, single-link ownership, byte size and read stability are checked. Collection reads immutable evidence through the store index, scope and digest; it never executes a command or reads a later scratch report.

The pure parser accepts UTF-8 `testsuites`/`testsuite` documents with nested suites, actual `testcase` elements, properties, result messages and system output. It rejects DTDs, processing instructions, unsupported elements, malformed XML, duplicate case identities, contradictory outcomes, more than 8 MiB, depth above 32, more than 100,000 elements or 50,000 cases. Summary attributes never supply counts. Skipped cases are not executed. Explicit retry failure/error elements preserve flaky facts.

Stable ID precedence: testcase `id`; agreeing `properties/property name="stackgate-id" value="..."`; safe testcase name; otherwise `junit_` plus SHA-256 of the JSON pair `[classname,name]`. Explicit IDs must satisfy the contract SafeId. Duplicate effective IDs fail collection. Missing required IDs, insufficient executed cases, zero execution and flaky evidence block success; assertion failures produce FAIL even with exit zero. Nonzero completion without assertion failures is TOOL_FAILURE. Process integrity errors retain ERROR precedence.

Original XML is retained unchanged as restricted/UNREDACTED evidence. Regular CheckResult facts contain IDs, counts and reason codes; failure message content is not copied into regular output. Report adapters must continue applying the shared redaction policy to ordinary exported facts.

Dependency: exact `saxes@6.0.0`, a strict SAX XML parser. Its [official repository](https://github.com/lddubeau/saxes) is archived; it is not represented as actively maintained. StackGate disables DTDs and imposes its own resource/dialect bounds. `patches/saxes@6.0.0.patch` changes only generic constraints and exact-optional namespace declarations to support the repository's strict TypeScript configuration; no runtime parser bytes or global compiler checks are changed. The retained `.stackgate-saxes-patch` directory is generated third-party patch workspace, excluded exactly like dependency material after automatic approval review blocked its removal.
